Variables Aleatorias y Distribuciones de Probabilidad

Estadística Inferencial UP — Capítulo 3 (Walpole)

1. Concepto de Variable Aleatoria

En el estudio de la estadística, realizamos experimentos cuyos resultados están sujetos al azar. Para analizar estos resultados de manera matemática, a menudo es conveniente asignarles una descripción numérica. La definición formal es la siguiente:

Definición: Una variable aleatoria es una función que asocia un número real con cada elemento del espacio muestral.

Utilizamos una letra mayúscula (por ejemplo, \(X\)) para denotar la variable aleatoria, y su correspondiente letra minúscula (\(x\)) para uno de sus valores específicos.

💡 Ejemplo 1: Extracción de bolas de una urna

De una urna que contiene 4 bolas rojas y 3 negras se extraen 2 bolas de manera sucesiva, sin reemplazo. Si definimos la variable aleatoria \(Y\) como el número de bolas rojas, los posibles resultados y sus valores correspondientes son:

Punto Muestral (Espacio Muestral)Valor \(y\) de la Variable Aleatoria \(Y\)
\(RR\) (Rojo, Rojo)2
\(RN\) (Rojo, Negro)1
\(NR\) (Negro, Rojo)1
\(NN\) (Negro, Negro)0

💡 Ejemplo 2: Devolución de cascos

Un empleado regresa 3 cascos de seguridad al azar a 3 obreros (Smith, Jones y Brown) que ya los habían probado. Si definimos la variable aleatoria \(M\) como el número de emparejamientos correctos (recibir el propio casco), los valores posibles para \(M\) son 0, 1 y 3.

Nota interesante: ¡El valor \(M = 2\) es imposible! Si dos obreros reciben su casco correcto, el tercero necesariamente también debe recibir el suyo.

2. Clasificación: Variables Discretas vs. Continuas

La naturaleza del espacio muestral determina el tipo de variable aleatoria:

  • Variable Aleatoria Discreta: Si su conjunto de resultados posibles es finito o se puede listar en una secuencia interminable con tantos elementos como números enteros existen (es decir, se puede contar). Ejemplos: \(Y\) (número de bolas rojas) y \(M\) (número de cascos correctos).
  • Variable Aleatoria Continua: Si puede tomar valores en una escala continua, correspondiente a todos los puntos de un intervalo completo de números reales. Generalmente representan mediciones físicas. Ejemplos: el peso de un lote de granos, el tiempo de reacción de un conductor, o la proporción de personas que responden a una encuesta por correo (\(0 \leq x \leq 1\)).

3. Distribuciones Discretas de Probabilidad

Una variable aleatoria discreta toma cada uno de sus valores con cierta probabilidad. La distribución de estas probabilidades se describe mediante una función:

Definición: El conjunto de pares ordenados \((x, f(x))\) es una función de probabilidad o distribución de probabilidad de la variable aleatoria discreta \(X\) si, para cada resultado \(x\) posible:

1. \(f(x) \geq 0\)
2. \(\sum_x f(x) = 1\)
3. \(P(X = x) = f(x)\)

💡 Ejemplo 3: Computadoras portátiles

Un embarque de 20 computadoras portátiles contiene 3 que están defectuosas. Si una escuela compra al azar 2 de estas computadoras, la distribución de probabilidad para el número \(X\) de computadoras defectuosas se calcula mediante combinaciones:

\(f(0) = P(X=0) = \frac{\binom{3}{0}\binom{17}{2}}{\binom{20}{2}} = \frac{68}{95}\)      \(f(1) = P(X=1) = \frac{\binom{3}{1}\binom{17}{1}}{\binom{20}{2}} = \frac{51}{190}\)      \(f(2) = P(X=2) = \frac{\binom{3}{2}\binom{17}{0}}{\binom{20}{2}} = \frac{3}{190}\)

Función de Distribución Acumulativa (FDA)

A menudo deseamos calcular la probabilidad de que el valor observado de una variable \(X\) sea menor o igual que algún número real \(x\):

Definición: La función de distribución acumulativa \(F(x)\) de una variable aleatoria discreta \(X\) con distribución de probabilidad \(f(x)\) es:

\(F(x) = P(X \leq x) = \sum_{t \leq x} f(t)\) , para \(-\infty < x < \infty\)

4. Distribuciones de Probabilidad Continua

A diferencia de las variables discretas, una variable aleatoria continua tiene una probabilidad de exactamente cero de adoptar cualquiera de sus valores individuales específicos (es decir, \(P(X = x) = 0\)). Por ello, sus probabilidades se definen sobre intervalos y se representan como el área bajo una curva:

Definición: La función \(f(x)\) es una función de densidad de probabilidad (fdp) para la variable aleatoria continua \(X\) si:

1. \(f(x) \geq 0\) , para toda \(x \in \mathbb{R}\)
2. \(\int_{-\infty}^{\infty} f(x) dx = 1\)
3. \(P(a < X < b) = \int_{a}^{b} f(x) dx\)

💡 Ejemplo 4: Error en temperatura de reacción

Suponga que el error en la temperatura de reacción en °C es una variable aleatoria continua con la fdp:

\(f(x) = \begin{cases} \frac{x^2}{3} & -1 < x < 2 \\ 0 & \text{en otro caso} \end{cases}\)

Podemos verificar que es válida porque:

\(\int_{-1}^{2} \frac{x^2}{3} dx = \left[ \frac{x^3}{9} \right]_{-1}^{2} = \frac{8}{9} - \left( -\frac{1}{9} \right) = 1\)

Y la probabilidad de que el error esté entre 0 y 1 °C es:

\(P(0 < X \leq 1) = \int_{0}^{1} \frac{x^2}{3} dx = \left[ \frac{x^3}{9} \right]_{0}^{1} = \frac{1}{9}\)

5. Distribuciones de Probabilidad Conjunta

En muchas situaciones prácticas, un experimento se modela a través de dos o más variables aleatorias de forma simultánea. Registramos sus probabilidades utilizando distribuciones conjuntas:

Definición (Caso Discreto): La función \(f(x,y)\) es una distribución de probabilidad conjunta de las variables discretas \(X\) y \(Y\) si:

1. \(f(x,y) \geq 0\) para todo \((x,y)\)
2. \(\sum_x \sum_y f(x,y) = 1\)
3. \(P(X=x, Y=y) = f(x,y)\)

Distribución Marginal: Permite conocer la distribución de probabilidad de una sola variable aislada sumando (o integrando) sobre la otra:

\(g(x) = \sum_{y} f(x,y)\)    (Caso discreto)        \(g(x) = \int_{-\infty}^{\infty} f(x,y) dy\)    (Caso continuo)

Distribución Condicional: Expresa la probabilidad de una variable dado que la otra ha tomado un valor específico conocido:

\(f(y|x) = \frac{f(x,y)}{g(x)}\) , siempre que \(g(x) > 0\)

Se dice que dos variables aleatorias \(X\) y \(Y\) son estadísticamente independientes si y solo si su probabilidad conjunta es exactamente igual al producto de sus distribuciones marginales individuales:

Definición: \(f(x,y) = g(x)h(y)\) para todo \((x,y)\) en sus rangos.

Si existe al menos un punto \((x,y)\) donde esta igualdad no se cumple, las variables se consideran dependientes.
